# Библиотека арта: как игра применяет ассеты

Игра собрана вокруг реестра: **имя файла = ключ иконки**. Достаточно положить файл в нужную
папку — ассет автоматически обновится на всех уровнях, в меню и в ростере. Кода писать не нужно.

**Канон стиля и воркфлоу рисования — [art/STYLE-GUIDE.md](../art/STYLE-GUIDE.md)**
(палитра, тени, двухтональный объём, правила текстур §7) и [art/README.md](../art/README.md)
(мастерская `art/` — единственная дверь для новых ассетов, цикл validate → preview → ревью →
перенос). Ассеты **не рисуются и не правятся напрямую в `src/assets/`**: гейт
`npm run validate-art` (автоматически перед смоук-тестами) проверяет конвенции и
синхронность `art/` ↔ `src/assets/`.

Полный список ключей с названиями и уровнями: [icon-reference.md](./icon-reference.md)
(регенерируется `npm run audit-icons`).

## Как смотреть результат

1. `npm run dev` → http://localhost:5173/?gallery — галерея всех ассетов
   (размеры 18/40/64px × светлый/тёмный/текстурный фон, статусы «дизайн/fallback»).
2. `npm run audit-icons` — консольный отчёт покрытия + обновление reference-документа.
3. Мастерская: `npm run preview-art` → открой `art/preview/index.local.html`
   (ч/б-режим «Нуар», все игровые цвета одежды, тайлы 3×3, стек клетки; HTML локальный,
   не коммитится).

## Папки

| Папка | Что кладём | Формат |
| --- | --- | --- |
| `src/assets/icons/items/` | иконки предметов (`plane.svg`, `windsock.svg`, …) | SVG |
| `src/assets/icons/themes/` | иконки тем главного меню (`airport.svg`, `zoo.svg`, …) | SVG |
| `src/assets/icons/persons/` | архетипы персонажей (`person-m-01.svg`, `person-f-02.svg`) | SVG |
| `src/assets/textures/` | текстуры пола (`wood.svg` или `wood.png`) | SVG или PNG |

Файл с ключом не найден → игра рисует текущую встроенную иконку (fallback). Поэтому можно
присылать партиями — ничего не ломается. Полное покрытие категории (см. audit) → встроенные
иконки категории удаляются из кода.

## Технические требования (проверяет `npm run validate-art`)

- Иконки: квадратный SVG, **viewBox 96×96**, контент в safe area ≈ 84×84; читаемость
  от 18px; вес ≤ 15 КБ.
- Текстуры: бесшовный тайл **SVG 256×256** (или PNG 256/512), вес ≤ 24 КБ.
- Чистота файла: без растровых вставок (`<image>`), текста, шрифтов, скриптов,
  фильтров, blend-режимов, `opacity`; `id` с префиксом ключа (`planeGradient1`) —
  файлы инлайнятся на одну страницу.
- Одежда архетипов: `fill="var(--person-clothing, #8A8A8A)"` — цвет приходит из геймплея.
- Strokes, градиенты и клипы — можно; тени и объём — сплошными тонами палитры (§2–3 гайда).

Стилевые правила (палитра, свет, тени, органический силуэт, «спокойный пол» §7) —
в [art/STYLE-GUIDE.md](../art/STYLE-GUIDE.md).

## Архетипы персонажей

- Именование: `person-m-01.svg` … `person-m-08.svg` (мужские), `person-f-01.svg` … (женские).
  Нумерация с `01`, последовательная.
- **Одежда красится игрой**: фигура одежды — отдельной фигурой с заливкой
  `fill="var(--person-clothing, #8A8A8A)"`. Цвет придёт из геймплея (цвет персонажа — игровая
  информация). Всё остальное (кожа, волосы, детали) — запечено в файле.
- Архетип выбирается игрой детерминированно по id персонажа — набор должен быть
  разнообразным внутри гендера. Допустимо поставлять гендеры партиями (м/ж независимо).
- Аудит проверяет: имя по конвенции + наличие `var(--person-clothing` в файле.

## Приёмка

1. Партия рисуется в мастерской `art/` по STYLE-GUIDE (эталоны §6 — копировать приёмы).
2. `npm run preview-art` → ревью в `art/preview/index.local.html`.
3. Утверждено → копия в `src/assets/…` (см. таблицу) → `npm run verify` (финальный гейт).
