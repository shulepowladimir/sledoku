# БРИФ: библиотека арта для игры «Следоку»

> Версия 1.0 (2026-09-01). Отправляется агенту-дизайнеру вместе с вложениями:
> `icon-reference.md`, `assets.md`, скриншотами игры из `docs/designer-brief/`.

## Контекст

Ты — иллюстратор, работающий в Figma. Отрисовываешь полную библиотеку арта для
детективной головоломки «Следоку» (судоку в обёртке нуарного детектива):
115 иконок предметов, 24 иконки тем уровней, 20 текстур пола, 8 архетипов
персонажей (пилот 4 мужских + 4 женских).

Технические требования жёсткие: файлы подставляются в игру АВТОМАТИЧЕСКИ ПО ИМЕНИ
ФАЙЛА. Любое отклонение от конвенции = файл не работает. Полный список ключей —
во вложении icon-reference.md; это твой главный рабочий чек-лист.

## Стиль

Америка 1940–1950-х, послевоенное время, нуарный детектив — но ЯРКИЙ, как
рекламные плакаты и pulp-обложки той эпохи. Не мрачный нуар, а «постерный» нуар:
сочные краски, графичность комикса, плакатная условность.

Опорные образы: туристические постеры 50-х, рекламные плакаты, обложки crime
comics, вывески дайнеров.

Ключевые приёмы:
- Плоские заливки + тонкая чёрная обводка (3px в масштабе 96×96) — по контуру
  фигуры И внутри, где нужно отделить детали друг от друга.
- Псевдо-3D «в плоскости»: жёсткая смещённая тень отдельной фигурой, БЕЗ блюра —
  как в плакатной печати. Тень = тот же силуэт, смещённый на 3–5px вниз-вправо.
- Чистый вектор, без фактуры бумаги и зерна.
- Персонажи — комиксные, с характером эпохи: федоры, тренчи, платья, яркие губы.

## Палитра (фиксированная, не выходить за неё)

| Роль                      | Hex      |
|---------------------------|----------|
| Красный (акцент)          | #C8102E  |
| Горчично-золотой          | #E0A94A  |
| Тил (тёмная бирюза)       | #2E6E65  |
| Кремовый (бумага)         | #F5E9D0  |
| Тёмно-синий (ночь)        | #1F3A5F  |
| Тёплый оранжевый          | #E0824A  |
| Чёрный (обводки, линии)   | #1A1A1A  |
| Тень (жёсткая, сплошная)  | #3A2A20  |

Правила: в иконке 2–4 цвета палитры + чёрная обводка. Тень — всегда сплошной
#3A2A20, никогда не полупрозрачный чёрный и никогда с размытием.

## Холст и техника (едино для всех иконок)

- Фрейм 96×96px, весь контент внутри safe area 84×84 (поля 6px со всех сторон).
- Обводка 3px (мелкие внутренние детали — 2.5px), толщина единообразна по набору.
- Перед экспортом все strokes перевести в контуры (Outline Stroke).
- ЗАПРЕЩЕНО: градиенты (старайся вовсе без них), blur / drop-shadow эффекты,
  blend modes, растровые вставки, текст, шрифты.
- Если градиент или маска неизбежны — назови слой в Figma с префиксом ключа
  (например «plane-grad-1»): Figma перенесёт имя слоя в id, а файлы встраиваются
  на одну страницу и id не должны конфликтовать.
- Вес файла ≤ 10 КБ.

## Категории

### 1. Иконки предметов — 115 шт. (ключи в icon-reference.md)
- Ракурс свободный (фронталь / профиль / 3/4) — что читается лучше для предмета,
  но стиль, толщина линий и приём теней ЕДИНЫЕ по всему набору.
- Иконка = игровой токен на доске: читаемость от 18px, силуэт узнаваем в ч/б.
- «Сидимые» предметы (стул, диван, лошадь, трон): посадочная зона читается
  по центру-низу.
- Имя фрейма = ключ точно: `plane`, `windsock`, `examTable` (camelCase!).

### 2. Иконки тем меню — 24 шт.
- «Обложка уровня»: один узнаваемый образ-эмблема без мелких деталей,
  финальный рендер 40–64px.
- Имя фрейма = тема: `airport`, `zoo`, `wizardschool`...

### 3. Текстуры пола — 20 шт.
- Фрейм 256×256 (сложные — 512). ОБЯЗАТЕЛЬНО бесшовный тайл: края стыкуются
  при повторении. Проверяй, дублируя фрейм рядом в сетку 2×2.
- Это пол, на котором стоят персонажи и предметы: спокойные приглушённые
  варианты палитры, без крупных тёмных пятен и контрастных деталей в центре.
- Экспорт: SVG; если нужна сложная фактура — PNG 256.
- Имя = ключ: `wood`, `asphalt`, `snow`...

### 4. Архетипы персонажей — пилот 4 мужских + 4 женских
- Именование: `person-m-01`…`person-m-04`, `person-f-01`…`person-f-04`.
- Фронтальная фигура в рост, комиксный стиль 40–50-х, характерные силуэты
  (детектив в шляпе, механик, светская дама, горничная...).
- КРИТИЧНО — одежда красится игрой произвольным цветом:
  - Вся одежда (включая шляпу, обувь, ремни) — отдельные фигуры верхнего
    уровня с ЕДИНОЙ заливкой #8A8A8A; разработчик подменит её программно.
  - Кожа, волосы, лицо, аксессуары (очки, трубка) — запечены обычными цветами.
  - Одежда должна хорошо смотреться с любым из игровых цветов:
    #2bc4c4 #3cbf7c #4d8dff #5fa8d3 #7cc9e8 #8a5a3a #9b7ce0 #b06ab3
    #c9536b #c98f38 #d9a441 #e0629b #e0824a #e0a94a
    поэтому внутри одежды — никаких чёрных пятен, только тонкая чёрная обводка
    по контуру.
- Читаемость от 18px (аватар в списке подозреваемых).

## Организация Figma-файла

Один файл «Следоку — Art Library», страницы:
- «00 Style Guide» — палитра, толщины линий, 2–3 примера тени, эталонный предмет;
- «01 Items», «02 Themes», «03 Textures», «04 Persons» — фреймы-ассеты,
  имя фрейма = ключ.

## Экспорт и передача

- Items / Themes / Persons: SVG, в настройках экспорта включён «Outline stroke».
- Textures: SVG или PNG 256 (512 для сложных).
- Имя файла при экспорте = имя фрейма, строго `ключ.svg` / `ключ.png`.
- Передавай архивом; структура папок не важна, важны только имена файлов.

## Порядок работы

1. Сначала — Style Guide + ПИЛОТНАЯ ПАРТИЯ для утверждения стиля:
   предметы `suitcase`, `plane`, `windsock`, `chair`, `toolbox`;
   тема `airport`; текстуры `wood`, `asphalt`; архетипы `person-m-01`, `person-f-01`.
2. После утверждения — остальное партиями по 15–25 файлов: предметы по списку
   icon-reference.md → темы → текстуры → архетипы (расширяем до 8+8).
3. Каждая партия проходит ревью в галерее игры; правки точечные.
